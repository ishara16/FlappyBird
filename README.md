# Description
A simple Flappy Bird clone built in Java using Swing and AWT for the GUI.
In this game, to control a small bird press Space to avoid from falling due of gravity.Our goal is to keep it flying by pressing the Space key to make it "flap" upward 
and pass through endless pairs of vertically aligned pipes without hitting them.If the bird collides with any pipe or touches the ground, it's Game Over. 
The game keeps track of the score based on the number of pipe pairs you've successfully passed.

Features
- Space key controls bird jump
- Randomly generated pipes with gaps
- Scoring system based on passing pipes
- Game Over screen with score display
- Automatic restart by pressing Space after game over
